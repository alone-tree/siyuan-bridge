# 思源标签：根因结论与展示需求

> 状态：已定稿（2026-09-25）。对应 issue：[alone-tree/siyuan-bridge#11](https://github.com/alone-tree/siyuan-bridge/issues/11)。

## 结论：写入不需要改动

AI 通过 `siyuan_create` / `siyuan_edit` 写入正文时，成对写法 `#标签#` 是否解析成思源标签，由思源编辑器设置决定：**设置 → 编辑器 → Markdown 行级语法 → `#foo#`（标签语法）**。

- 开关开启后，桥写入的行中、行首、相邻（`#甲##乙#`）写法全部正常落成真标签：`blocks.tag` 有值、标签面板可见。
- 开关关闭时，包括思源原生接口在内的所有 Markdown 写入都不解析标签，落成普通文字。与桥无关。

因此思源桥写入路径不做任何改动。用户遇到「写入的 `#标签#` 是纯文本」时，打开该开关即可。该指引已写入 README 常见问题（中英双语）。

实测依据（2026-09-25，思源 3.8.5）：开关关闭时，绕开桥直接调思源原生 `createDocWithMd` / `appendBlock` 写同样内容同样落纯文本，桥嫌疑排除；开启开关后，桥写入的三种位置全部落成真标签。

## 需求一：搜索/阅读/列表展示文档属性标签

文档属性标签写在文档块（`type='d'`）的 `blocks.tag` 列上，不在正文里。AI 通过 `siyuan_read`、`siyuan_find`、`siyuan_list` 都看不到它；全文搜索能命中，但只返回标题片段，AI 不知道命中与标签的关系。

在三个工具的返回中补充文档属性标签：

- 数据源：文档块 `tag` 列（本地索引 `docs.jsonl` 已有 `tags` 字段）。
- 展示形式：`tag：#甲# #乙#`，多标签空格分隔。
- 只在文档真有标签时显示；没有标签的文档不显示「tag：无」。
- `siyuan_read`：文档信息区展示该文档的标签。
- `siyuan_find`：文档有标签就展示全部标签，不做「本次命中是否因标签」的归因。
- `siyuan_list`：文档列表行带上标签。

## 需求二：编辑文档标签（`siyuan_doc_manage` 新增 `set_tags`）

技术前提（实测）：`/api/attr/setBlockAttrs` 对文档块设置 `tags` 属性即可编辑文档标签；输入必须是**逗号分隔、不带 `#` 的裸名**；空值清除全部；SQL `tag` 列有秒级索引延迟。

### 契约

- 归属 `siyuan_doc_manage`（文档级事实变更，语义同 rename），不放 `siyuan_edit`（正文块工具）。
- `tags` 必填（string，空串 = 清除全部）；AI 侧写法 `tags="#标签1# #标签2#"`，工具描述只教空格分隔。
- 权限 `read_write` + `confirmed=true` + 写前快照；写后 `pushMsg` + 安全刷新索引（否则 read/list/find 读不到新值）。
- 返回：设置成功信息、标签数量、逐个标签（`#名称#` 形式）、快照与索引状态。

### 解析规则（严格解析，模糊即报错）

1. 只认半角 `#` 成对定界；标签 = 两个 `#` 之间的内容，strip 首尾空白后必须非空。
2. 名称内合法字符：空格、全角 `＃`、`，` `、` `；` `/`（官方层级标签）、`-` `.` 等一切非禁字符。
3. 名称内禁止字符（报错）：官方特殊符号清单 `` ` * _ [ ] ! \ < > & ~ $ ( ) { } = #`` 加半角逗号 `,`。依据：官方用户指南「请勿在标签中使用特殊符号（无法全局搜索、标签面板无法重命名删除）」；半角逗号是思源存储分隔符（内核实测按逗号拆分）。
4. 名称内合法但思源存储相关的实测结论：空格/顿号/分号/全角逗号内核不拆分，均合法。
5. **完整性校验**：移除全部成对片段后，剩余字符必须全部分隔符（空白、`,` `，` `、` `;` `；`），否则报错；裸名（无 `#`）、未闭合 `#`、孤立 `#`、全角 `＃` 包裹均落入报错。
6. 去重保序。

### 报错文案（附正确示例）

- 无法识别（不成对 `#`、裸名、残留字符）：提示成对半角井号 + 空格分隔的正确写法 `tags="#标签1# #标签2#"`，并说明标签名称本身勿用半角井号。
- 名称含禁止字符：列出命中的字符 + 完整禁止清单 + 官方原因（无法全局搜索、无法重命名删除；半角逗号是存储分隔符）。
- 空名称（`# #`）：每个 `# #` 之间必须有标签名。

### 字符规则依据

| 类别 | 判定 | 依据 |
|---|---|---|
| 官方特殊符号 + `#` | 禁止 | 官方用户指南「标签」章节警告 |
| 半角逗号 `,` | 禁止 | 内核实测：思源按半角逗号拆分标签 |
| `/` | 合法 | 官方层级标签 `#A/B/C#` |
| 空格/顿号/分号/全角逗号/全角 `＃` | 合法 | 内核实测：内核不拆分、searchTag 正常聚合 |
