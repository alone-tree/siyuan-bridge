# 工作空间索引创建指南

工作空间索引是一份以文档路径为主的语义导航，保存在系统笔记本的《工作空间索引》中。它由 AI 在用户要求时创建或更新，系统不会自动扫描并重写。

## 阅读深度

- **快速（默认）**：每个笔记本阅读一篇枢纽文档，例如标题含“索引”“必读”“概述”“项目背景”或 README 的文档。
- **详细**：除枢纽文档外，每个重点笔记本再阅读 2–4 篇重要文档。

不能只凭标题撰写内容摘要。没有读过的文档只记录路径，不写摘要。

## 创建流程

1. 调用 `siyuan_start` 获取笔记本概览和统计。
2. 对每个有内容的笔记本调用 `siyuan_list`，判断它是深层树、扁平集合还是“索引页 + 子文档”结构。
3. 按用户指定的深度，用 `siyuan_read` 阅读枢纽文档。
4. 按下面的模板生成索引。
5. 用户已经要求创建索引时，这句话本身就是写入确认；使用 `siyuan_create` 覆盖《工作空间索引》的占位内容。

```markdown
# 知识库索引
> 生成日期 YYYY-MM-DD

## 快速导航
| 问题领域 | 对应笔记本 |
|---------|-----------|
| ... | ... |

## 笔记本名称（N 篇文档）

> 结构：一句话描述组织方式
> 优先级：

### /路径/到/关键/子树

- `doc-id` 文档标题
  - AI 摘要：只总结实际读过的内容
```

## 内容规则

- 快速导航宁缺毋滥，错误路由比没有路由更糟。
- `> 优先级：` 默认留空，供用户填写；更新时必须原样保留。
- 不覆盖用户在索引中添加的修正、说明和其他人工内容。
- 不超过 20 篇文档的笔记本可以逐篇列出；更大的笔记本按路径和结构模式概括。
- 整份索引尽量控制在 300 行以内。
- 系统笔记本中的指南、About 和 Privacy Rules 不是用户知识资料，不纳入内容总结。

## 更新流程

1. 调用 `siyuan_operate(action="refresh")` 刷新客观索引。
2. 调用 `siyuan_start` 比较当前概览和已有工作空间索引。
3. 只重新检查新增、删除或可能变化的笔记本和文档。
4. 阅读新增或发生变化的关键文档，不凭标题猜摘要。
5. 用引用阅读取得块 ID，再用 `siyuan_edit` 局部更新《工作空间索引》。
6. 保留用户写入的优先级、修正和其他人工内容。

完成后向用户说明新增、删除和更新了哪些索引内容。
