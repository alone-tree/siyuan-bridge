## 定位资料

- 工作空间索引用于快速判断相关内容可能在哪个笔记本或路径，但它只是导航，不是事实来源。找到目标后仍应阅读原文。
- 不必固定按照 list、find、read 的顺序操作。问题指向明确时直接搜索或读取；需要了解笔记本结构时再查看文档树。
- 系统笔记本主要存放思源桥配置和 AI 指引，不应把其中的指南、About 或隐私规则当作用户知识资料。

## 编辑与块引用

- 编辑动作应根据用户希望得到的最终结构选择，不要为了块 ID 本身改变方案。没有反链时，旧块 ID 保留或消失通常没有实际影响。
- 会删除块 ID 的操作会自动检查反链。发现反链后工具会拒绝操作，并针对本次被引用内容提示何时应保留 ID、何时可以请求用户允许破坏引用。
- 按冲突提示重新规划编辑。只有用户明确允许破坏本次报告的引用后，才能使用 `reference_policy=break`；它不是后续操作的通用授权。

## 系统笔记本

- **MCP 使用指南**：补充 MCP 的使用原则，用户可以修改。
- **用户个性化要求**：用户写给 AI 的长期要求；AI 应遵守，不主动重写。
- **工作空间索引**：新会话的知识库导航，由 AI 在用户要求时创建或更新。
- **工作空间索引创建指南**：创建和更新索引时遵循的规则，用户可以修改。
- **关于思源桥**：面向用户的产品说明，插件升级时可能覆盖。
- **隐私规则**：由用户维护，AI 不得读取或修改。

除隐私规则外，系统笔记本中的文档都按普通可见文档处理。
